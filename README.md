# 🎯 Quiz Management System (Frontend Only)

A simple, clean, and fast **Quiz Management System** built using **Vite + React + TailwindCSS**, with **no backend**.  
All quiz data, admin login status, and created questions are stored in **localStorage**.

## 🚀 Tech Stack
- Vite + React
- React Router
- TailwindCSS
- LocalStorage

## 🔐 Admin Login Credentials
```
Username: admin
Password: 123
```

## ✨ Features
### Public User
- View quizzes  
- Attempt quizzes  
- MCQ / True-False / Text types  
- Score calculation  

### Admin
- Dummy login  
- Create quizzes  
- Add questions  
- Data saved in localStorage  

## 📦 Setup
```
npm install
npm run dev
```
